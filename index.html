Security that holds up in the database

Access control is not a checkbox in our UI. It is enforced where the data lives.

Row-level isolation

Tenant, matter, and vendor walls are PostgreSQL row-level security policies. A firm's session physically cannot read another firm's rows, or your internal ones.

Append-only audit

Every material change lands in an append-only audit ledger from the very first migration. Who, what and when, in a ledger that cannot be quietly rewritten.

Least-privilege by default

The application itself runs on a least-privilege database login. Admin paths, approval gates and role policies are enforced server-side, not styled client-side.
